# Справочник команд терминала macOS

Краткий обзор часто используемых команд в **Terminal.app**, **iTerm2** и других оболочках (по умолчанию **zsh**).

---

## Навигация и файловая система

| Команда | Описание |
|---------|----------|
| `pwd` | Показать текущий каталог (полный путь). |
| `cd путь` | Перейти в каталог. `cd` без аргументов — домашняя папка; `cd -` — предыдущий каталог. |
| `cd ~` | Домашняя директория пользователя. |
| `ls` | Список файлов в текущем каталоге. |
| `ls -la` | Подробный список, включая скрытые файлы (`.`). |
| `ls -lh` | Размеры в человекочитаемом виде (K, M, G). |
| `mkdir имя` | Создать каталог. `mkdir -p a/b/c` — создать всю цепочку. |
| `rmdir имя` | Удалить пустой каталог. |
| `rm файл` | Удалить файл. |
| `rm -r каталог` | Рекурсивно удалить каталог и содержимое. |
| `rm -rf каталог` | Принудительное рекурсивное удаление (осторожно, без корзины). |
| `cp источник назначение` | Копировать файл или каталог. `-r` для каталогов. |
| `mv источник назначение` | Переместить или переименовать. |
| `touch файл` | Создать пустой файл или обновить время модификации. |
| `open .` | Открыть текущую папку в Finder. |
| `open файл` | Открыть файл приложением по умолчанию. |
| `open -a "App" файл` | Открыть файл указанным приложением. |

## Просмотр и поиск

| Команда | Описание |
|---------|----------|
| `cat файл` | Вывести содержимое файла целиком. |
| `less файл` | Постраничный просмотр (q — выход, / — поиск). |
| `head -n 20 файл` | Первые 20 строк. |
| `tail -n 20 файл` | Последние 20 строк. |
| `tail -f файл` | «Следить» за добавлением строк (логи). |
| `wc -l файл` | Количество строк. |
| `find . -name "*.swift"` | Поиск файлов по имени от текущей точки. |
| `find . -type f -mtime -7` | Файлы, изменённые за последние 7 дней. |
| `grep "текст" файл` | Поиск строки в файле. |
| `grep -r "текст" .` | Рекурсивный поиск в каталоге. |
| `grep -i "текст"` | Без учёта регистра. |
| `grep -n "текст"` | С номерами строк. |
| `which команда` | Путь к исполняемому файлу команды. |
| `whereis команда` | Расположение бинарника, man и исходников (если есть). |

**macOS-специфика:**

| Команда | Описание |
|---------|----------|
| `mdfind "запрос"` | Spotlight: поиск файлов по содержимому/имени. |
| `mdls файл` | Метаданные файла (Spotlight). |

## Права и владельцы

| Команда | Описание |
|---------|----------|
| `ls -l` | Права, владелец, группа, размер, дата. |
| `chmod 755 файл` | Права в восьмеричном виде (rwx для owner/group/other). |
| `chmod +x скрипт` | Добавить право на выполнение. |
| `chown user:group файл` | Сменить владельца (часто нужен `sudo`). |
| `sudo команда` | Выполнить команду от root (запрос пароля). |

## Диски и место

| Команда | Описание |
|---------|----------|
| `df -h` | Занятое/свободное место на смонтированных томах. |
| `du -sh каталог` | Размер каталога (суммарно). |
| `du -sh *` | Размер каждого элемента в текущей папке. |

## Процессы и система

| Команда | Описание |
|---------|----------|
| `ps aux` | Список процессов (все пользователи). |
| `top` | Интерактивный монитор процессов (q — выход). |
| `htop` | Улучшенный top (через Homebrew, если установлен). |
| `kill PID` | Завершить процесс по ID. |
| `kill -9 PID` | Принудительное завершение. |
| `killall ИмяПроцесса` | Завершить все процессы с таким именем. |
| `lsof -i :3000` | Кто слушает порт 3000. |
| `lsof файл` | Какие процессы держат файл открытым. |
| `uname -a` | Ядро и архитектура системы. |
| `sw_vers` | Версия macOS (ProductVersion, Build). |
| `sysctl -n machdep.cpu.brand_string` | Модель процессора. |
| `uptime` | Время работы системы и load average. |
| `whoami` | Текущий пользователь. |
| `id` | UID, GID и группы. |
| `history` | История команд оболочки. |
| `clear` | Очистить экран терминала. |

## Сеть

| Команда | Описание |
|---------|----------|
| `ping host` | Проверка доступности хоста (Ctrl+C — стоп). |
| `ping -c 4 host` | Четыре пакета и выход. |
| `curl URL` | HTTP-запрос, вывод тела ответа. |
| `curl -I URL` | Только заголовки ответа. |
| `curl -O URL` | Скачать файл с сохранением имени. |
| `wget URL` | Скачивание (часто через `brew install wget`). |
| `ifconfig` | Сетевые интерфейсы и IP (на новых macOS иногда `ipconfig getifaddr en0`). |
| `ipconfig getifaddr en0` | IP Wi‑Fi (en0) или Ethernet (en1 и т.д.). |
| `netstat -an \| grep LISTEN` | Слушающие порты. |
| `scutil --dns` | Настройки DNS. |
| `networksetup -listallhardwareports` | Список сетевых портов и устройств. |
| `ssh user@host` | Подключение по SSH. |
| `scp файл user@host:/path` | Копирование файла по SSH. |
| `rsync -avz src/ user@host:dest/` | Синхронизация каталогов (локально или по SSH). |

## Оболочка zsh (macOS по умолчанию с Catalina+)

| Команда / синтаксис | Описание |
|---------------------|----------|
| `echo $SHELL` | Текущая оболочка. |
| `echo $PATH` | Пути поиска исполняемых файлов. |
| `export VAR=значение` | Переменная окружения для текущей сессии. |
| `alias ll='ls -la'` | Псевдоним команды. |
| `source ~/.zshrc` | Перечитать конфиг zsh. |
| `Ctrl+R` | Интерактивный поиск по history. |
| `Ctrl+C` | Прервать текущую команду. |
| `Ctrl+D` | EOF / выход из оболочки (если пустая строка). |
| `Cmd+T` (Terminal) | Новая вкладка. |

Файлы конфигурации: `~/.zshrc`, `~/.zprofile`, `~/.zshenv`.

## Полезные сочетания и перенаправление

| Синтаксис | Описание |
|-----------|----------|
| `команда > файл` | Перезаписать stdout в файл. |
| `команда >> файл` | Дописать stdout в файл. |
| `команда 2>&1` | stderr в stdout. |
| `команда \| другая` | Передать вывод в следующую команду (pipe). |
| `команда &` | Запуск в фоне. |
| `jobs` | Список фоновых задач оболочки. |
| `fg %1` | Вернуть задачу №1 на передний план. |
| `команда1 && команда2` | Вторая только если первая успешна. |
| `команда1 \|\| команда2` | Вторая только если первая с ошибкой. |

---

## Безопасность и приватность

- **`rm -rf`** и **`sudo`** — проверяй путь дважды; отмены через корзину нет.
- Не копируй из интернета **`curl ... \| bash`** без просмотра скрипта.
- **`sudo`** запрашивает пароль пользователя macOS, не отображает символы при вводе.
